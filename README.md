
# Nutrition Tracker（栄養管理アプリ）

## 1. アプリ概要

日々の食事・栄養摂取量・体重を記録し、健康管理をサポートするWebアプリケーションです。

食事ごとのカロリーやPFC（たんぱく質・脂質・炭水化物）を記録し、1日の摂取量と目標値を比較できます。また、体重の推移をグラフで確認できます。

ユーザー登録・ログイン機能を備えており、ユーザーごとに食事記録・体重記録・栄養目標を管理できます。

## 2. 開発目的

日々の栄養管理をより簡単に継続できる仕組みを作ることを目的として開発しました。

JavaとSpring Bootを用いたWebアプリケーション開発を通じて、MVC構成、データベース操作、入力値検証、認証・認可、画面表示などの技術を実践的に学ぶことも目的としています。

また、複数ユーザーが利用するWebアプリケーションを想定し、ユーザー認証とデータの分離を実装することで、実用的なシステム設計への理解を深めました。

## 3. 主な機能

### ユーザー認証・データ管理

- ログイン・ログアウト機能
- Spring Securityによる認証・アクセス制御
- BCryptによるパスワードのハッシュ化
- ユーザーごとの食事・体重・栄養目標データの管理
- 未ログインユーザーのアクセス制限

### その他
- 入力値のバリデーション
- エラーメッセージの表示
- エラー画面の表示

## 5. システム構成

Spring Bootを使用したMVCアーキテクチャを採用しています。

- **Controller**：HTTPリクエストの受付、画面遷移、入力処理
- **Service**：ビジネスロジック、データ操作、ユーザー管理
- **Repository**：Spring Data JPAによるデータベースアクセス
- **Entity**：食事・体重・栄養目標・ユーザー情報の管理
- **View**：ThymeleafによるHTML画面の生成

### 認証・データ管理

Spring Securityを利用してユーザー認証を実装しています。

ユーザーのパスワードはBCryptでハッシュ化してデータベースに保存します。

食事記録・体重記録・栄養目標をユーザー情報と関連付け、ログイン中のユーザーに対応するデータを取得・管理する構成としています。

## 6. ローカルでの起動方法

### 前提条件

- Java 17以上
- Git

### 起動手順

**① リポジトリをクローン**

```bash
git clone https://github.com/t824-t/nutrition-tracker.git
cd nutrition-tracker
```

**② アプリケーションを起動**

Windowsの場合：

```powershell
.\mvnw.cmd spring-boot:run
```

macOS / Linuxの場合：

```bash
./mvnw spring-boot:run
```

**③ ブラウザでアクセス**

http://localhost:8080

**④ ユーザー登録**

初めて利用する場合は、以下のページからユーザー登録を行います。

http://localhost:8080/register

登録後、ログインして食事・体重・栄養目標の管理を行えます。

ローカル環境ではH2データベースを使用します。

| OS | Amazon Linux 2023 |
| Webサーバー | nginx |

↓ HTTPS（443番ポート）
nginx

↓
